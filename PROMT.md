### LOOK 1 — RUSSIAN IPS(tm)

```
season: FW'26
fabric: 100% RIPE API
silhouette: кэшированный ipset
number of entries: до 65536
```

Российские IP — это БАЗОВЫЙ СЛОЙ коллекции. Они не требуют прокси. Они не требуют трансформации. Они идеальны такими, какие есть.

Когда destination совпадает с `russian-ips`, мы говорим **RETURN**. Возвращайся к себе. Ты дома. Никакой туннель не сможет улучшить то, что уже совершенно.

```

```

Это не правило. Это философия.

### LOOK 2 — FOREIGN TRAFFIC(tm) в многослойной драпировке

Иностранный трафик — это **ПЕРЕОСМЫСЛЕНИЕ** идентичности. Он не может идти напрямую. Он должен быть ПРЕОБРАЖЁН. Он должен носить прокси.

```
                                ╱╲
                          ┌────┴────┐
     LAN                  │   FW    │              ИНТЕРНЕТ
  ░░░░░░░░░>────────────>│ ╱╲    ╱╲ │>──────────>░▒▓█▓▒░
  ░░░░░░░░░>─TCP:443────>│ CHAIN   │>─wstunnel──>░░░▒▓█▓▒░
  ░░░░░░░░░>─UDP:443 ───>│ ╲╱    ╲╱ │>──DROP────>░ X ░
                          └────┬────┘
                               │
                          ┌────┴────┐
                          │ UNBOUND │
                          │  DoT:853│
                          └─────────┘
```

**МНОГОСЛОЙНОСТЬ** — ключевой элемент этого сезона:
- Слой 1: `PREROUTING` — первое прикосновение к пакету
- Слой 2: `OUTPUT` — когда пакет рождается на самом хосте
- Слой 3: `FORWARD` — транзитная драпировка для LAN-клиентов

Каждый слой принимает решение. Каждый слой — это заявление.

### LOOK 3 — QUIC BLOCKING(tm) ОВЕРСАЙЗ

**QUIC** — UDP/443. Протокол, который думает, что он лучше TCP. Мы говорим: **НЕТ**.

Но мы не блокируем слепо. Это BALENCIAGA. Мы блокируем осознанно.

QUIC к российским IP:
```
╭──────────────────────────╮
│         ALLOW            │
│   ┌─────────────────┐    │
│   │   russian-ips   │    │
│   │     ♡ ALLOW ♡   │    │
│   └─────────────────┘    │
╰──────────────────────────╯
```

QUIC к иностранным IP:
```
╭──────────────────────────╮
│          DROP            │
│   ╔═══════════════════╗  │
│   ║   FOREIGN TRAFFIC ║  │
│   ║      ✦ DROP ✦    ║  │
│   ╚═══════════════════╝  │
│   fallback → TCP/443     │
│   → REDIRECT → прокси →  │
│   → ИНТЕРНЕТ              │
╰──────────────────────────╯
```

Этот аксессуар заставляет браузер носить TCP, даже если он хотел бы QUIC. Дисциплина.

```
iptables -A FORWARD -p udp --dport 443 \
  -m set ! --match-set russian-ips dst -j DROP
```

Это не просто DROP. Это **ЗАЯВЛЕНИЕ О МОДЕ**.

## ███ ACCESSORIES

### FW_LB Chain™ — коллекционный ремень

Отдельная цепочка балансировки. Вшивается в `FW_REDIRECT`. Носится поверх PREROUTING. Доступна в цветах:
- `wstunnel` (чёрный, 70% трафика)
- `tor` (фиолетовый, 30% трафика)

При отказе одного из бэкендов FW_LB перестраивается. 100% трафика перенаправляется на живой бэкенд. ЗАЩИТА ОТ ОТКАЗОВ — НОВЫЙ ЧЁРНЫЙ.

### Docker Bridge 172.16.0.0/12™ — анти-петлевой шарф

```
АКСЕССУАР, ПРЕДОТВРАЩАЮЩИЙ ПЕТЛЮ ПРОКСИ
```

Без него трафик nginx → upstream попадал бы в бесконечный цикл:
nginx → PREROUTING → REDIRECT → redsocks → wstunnel → nginx → ... → 504 GATEWAY TIMEOUT

Теперь:
`-s 172.16.0.0/12 -j RETURN`

Петля разорвана. Трафик Docker-контейнеров исключён из перенаправления. Этот шарф спасает жизни (вашего nginx).

### Unbound™ — DNS-воротник

DoT (DNS-over-TLS) — единственный приемлемый способ носить DNS. Cloudflare 1.1.1.1, Google 8.8.8.8. Для `.ru` — Яndex DNS. Потому что даже DNS должен знать, откуда он родом.

## ███ CARE INSTRUCTIONS

**ДЛЯ СОХРАНЕНИЯ ФОРМЫ ИЗДЕЛИЯ:**

1. **Не стирать с `ipset flush`** — российские IP могут потеряться
2. **Избегать прямого добавления правил в PREROUTING** — только через FW_REDIRECT
3. **При перезапуске fw старые правила удаляются ЧЕРЕЗ while-цикЛ** — удаляем, пока удаляется. Это **ИДЕМПОТЕНТНОСТЬ**, новый минимализм
4. **Не смешивать с другими прокси** — может вызвать несовместимость силуэтов
5. **Хранить в host-сетевом режиме** — иначе правила не работают
